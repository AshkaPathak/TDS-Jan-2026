# GA7 — Q9: Presentation Prompt Structural Repair

## Problem Summary

The task is to identify missing structural components in a broken prompt using a 6-component schema and repair it by adding only the missing components without modifying existing text.

---

## Missing Components

Missing components: B, C, F

- B (Output format specification) is missing → required to define deliverable structure  
- C (Data field reference) is missing → required to ground output in actual data  
- F (Required action recommendation) is missing → required to ensure actionable insight  

---

## Completed Prompt

Create a presentation artifact for the following task: quarterly placement outcomes summary for academic leadership.  
Audience: for deans with non-technical backgrounds.  
Tone/style: in a data journalism explainer style.  
Length constraint: in 100 to 150 words.  
Output format specification: present as a concise executive slide-style summary using bullet points.  
Data fields: include placement rate, median salary, number of offers, and comparison with previous quarter.  
Action recommendation: include a clear, actionable recommendation to improve placement outcomes in the next quarter.
